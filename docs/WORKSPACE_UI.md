# 工作台交互与偏好

## 对话栏

- 桌面宽度（768px 及以上）对话栏占据独立列，不使用遮罩；切换或新建对话不自动收起它。窄屏保持可关闭的抽屉。
- 不在品牌旁放重复 X。浏览器/旧客户端的唯一折叠按钮在聊天页顶栏；v0.6.0 桌面客户端将它移至窗口顶栏，并隐藏页面内的重复按钮。
- 管理员可点击 Project Ardor 品牌打开管理入口；普通用户品牌不是菜单。UI 隐藏不替代后端 ROLE_ADMIN 鉴权。
- 最近对话可折叠；搜索首版按当前已加载的活动对话标题筛选，不是消息全文或知识库检索。归档对话仍由独立入口查看。
- 固定对话栏折叠时，悬停左侧对话图标可临时查看最近 20 个活动对话；其他模块页同样可预览并跳转。移入浮层保持，移开或点击外部关闭；固定栏已展开时不重复弹出。支持键盘焦点、方向键进入及 Escape 关闭，可在浮层展开固定栏；触屏点击图标使用正常抽屉，不依赖悬停。预览只读取当前账户的标题列表，不加载对话正文或调用模型。
- 通知弹窗查询最近 30 个后台任务，显示其中已完成和失败的结果。它不会把打开通知当成已读；查看具体报告仍由原业务的完成版本已读接口处理。

## 重命名

每次助手完成回复后，后端提交事件，由 `ConversationTitleService` 异步用有效模型的 QUICK 深度概括最近六条消息（每条最多 1200 字符）。失败保留原标题，不阻断聊天；这是一笔额外的模型调用。保存时同时检查用户归属、手动命名标志及最新助手消息 ID，避免旧任务覆盖较新标题。

用户手动命名使用应用内表单，而不是 Electron 不支持的 `window.prompt`。请求沿用受鉴权的 PATCH 接口；失败保留输入并就地报错；成功后 `titleManuallySet=true`，后续自动命名不覆盖它。手动标题沿用后端的 1–240 个 UTF-16 字符限制；自动生成标题另限 60 个 Unicode 字符。

## 侧栏偏好

- 「更多 → 自定义侧栏」与「设置 → 通用与侧栏」提供同一编辑入口。
- 对话入口始终保留；用户选择其他模块常驻，其余保留在更多菜单，不删除业务模块。
- 配置通过受鉴权的 `GET/PUT /api/profile/sidebar` 保存在 `user_profiles.preferences.sidebar`，浏览器与桌面使用同一账户配置。仅允许已知模块路径，对话入口不可移除；界面偏好不赋予业务权限。
- 默认读取不初始化账户配置。只有账户尚无配置且此设备存在旧 `ardor:workspace-rail:v1:<账户 ID>` 自定义时才尝试迁移；首次迁移也校验版本，不能覆盖另一设备先保存的配置。旧本地布局保留，可在编辑框中载入后手动保存。
- `ardor:workspace-rail:v2:<账户 ID>` 仅为账户配置的本地缓存。切换账户校验返回归属，写入同时检查认证用户、预期账户及配置版本；旧客户端或旧弹窗收到 409 后保留草稿，用户核对再保存才覆盖新版本。个人资料更新不重写未修改的偏好字段。
- 聚焦窗口、同源标签页更新和可见页面每 30 秒刷新配置，未保存的编辑选择不随后台同步清空。损坏缓存回退默认值；服务不可用时保留最后布局，保存失败保留选择并明确提示，不宣称已同步。恢复默认要点击保存才生效，取消不修改设置。

## 分类设置

通用与侧栏、个人资料、账户安全、模型与服务、使用额度、桌面应用分区展示。个人 API 按服务逐项选择，保留管理员默认优先规则。类别和服务切换用隐藏面板而非卸载表单，避免未保存输入消失；刷新或离开设置页仍不保证保存这些草稿。

语言只在「通用与侧栏」切换。思考深度滑条显示 Low / High / Max，分别沿用 QUICK / STANDARD / DEEP，Auto 沿用 AUTO；显示名称不是承诺所有服务商都有同名原生参数。原生参数与提示适配仍由后端 reasoning profile 决定。支持键盘 Home/End/方向键，弹层外部点击与 Escape 关闭，尊重减少动态效果设置。附件弹层也按外部点击与 Escape 关闭；点击内部资料仅切换引用，不意外关闭。

参考官方设置分区方法，而非照搬开发专属选项：[OpenAI settings documentation](https://learn.chatgpt.com/docs/developer-settings)。

## 回归

前端 typecheck、lint、build 后运行 `node tests/workspace-ui.mjs`。脚本启动 3101 端口的生产前端，所有 API 用合成响应替代，不读取真实账户或调用付费模型。验证重命名失败重试与刷新、无原生 prompt、桌面并排、折叠/搜索/通知、侧栏保存与账户隔离、坏缓存回退、分类草稿保留与窄屏无横向溢出。默认使用 Playwright Chromium；本机可用 `ARDOR_UI_BROWSER_CHANNEL=msedge` 指定已安装的 Edge。CI 在 frontend-quality 工作流执行此测试。
