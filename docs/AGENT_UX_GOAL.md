- [ ] 已接受消息留在记录中，断流、刷新、切页不退回成未发送草稿。

- [ ] Agent 业务工具增删改查逐次展示明确权限确认，批准才执行；拒绝、超时、恢复不自动授权。

- [ ] 核对各模块 Agent 操作能力，补齐缺口；学习重点补删除与必要修改工具、用户删除按钮和关联数据一致性。

## 功能标签与创建入口（追加需求）

- [ ] 输入框支持在开头键入 `@` 或 `$`，从真实可用功能/服务目录选择；不是普通字符装饰。
- [ ] 选择后渲染为可点击的链接式标签，不显示原始 `@` / `$`；可查看功能说明或修改选择，也可移除。
